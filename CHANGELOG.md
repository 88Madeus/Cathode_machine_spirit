# История версий

## 0.4.0 — 2026-10-25

- Проект перенесён в репозиторий: автотесты pytest (кривые, настройки, экспорт,
  движок со сбоями прибора и связи, LAN через pyvisa-py, окно), GitHub Actions
  на Python 3.8 / 3.12 и Windows, эмулятор прибора `tools/fake_itech.py`.
- Версия программы — в заголовке окна, в журнале событий и на листе «Сессия» в Excel.

## 0.3 — вторая независимая проверка

- Ограничение тока источником проверяется на каждом отсчёте: рост запрещён, уставка
  подтягивается к току (≤ 0,5 А выше), снижение и авария не прерываются.
- ▲ / ▼ не ведут в обратную сторону; «▲ до 0» не включает выход.
- При подключении прибор не меняется (в том числе `VOLT:LIM`); предел приводится
  к настройке по команде оператора без скачка.
- Полная ресинхронизация ответов после обрыва связи; защиты по двум отсчётам;
  фильтр неправдоподобных отсчётов.
- Окно сразу показывает закрытие сессии во время сохранения журнала; настройки,
  применённые в этот момент, не теряются.
- Мелкие исправления m1–m10 (см. `docs/design_decisions.md`).

## 0.2 — первая проверка и экспорт в Excel

- Выравнивание обмена с прибором, подтверждение отключения выхода, сверка тока
  с уставкой, запрет скачка больше 0,5 А одной командой, dP/dt от уставки,
  проверка настроек, запрет сна Windows.
- Журнал сессии в Excel: дата, время начала и окончания, итоги, журнал, события, графики.

## 0.1 — приложение с окном

- Подключение с выбором адреса, ▲ / ▼ по кривой из любой точки, СТОП, ручная уставка,
  передача на панель и возврат, график, журнал CSV.
- Кривая разогрева и остывания — по протоколам ПР-8 (30.09–06.10.2026).
