# ПР-8 · Накал катода LaB₆

Программа для бережного разогрева, удержания и остывания катода LaB₆ установки ПР-8
от источника ITECH IT6012D-300-150 с ноутбука. Ток меняется только плавно, по кривой из
протоколов ручных нагревов; оператор в любой момент может остановить движение,
развернуть его, задать ток вручную или отдать управление на панель прибора.

> **Статус:** программа проверена на модели нагревателя и на эмуляторе прибора по LAN,
> на настоящем IT6012D ещё не запускалась. Перед работой на установке — пройти
> [план испытаний](docs/test_plan.md).

## Что умеет

- **Подключение** по LAN (Socket / VXI-11), USB / GPIB / COM через VISA, по адресу вручную
  или к модели без прибора. «Проверить связь» только спрашивает `*IDN?`.
- **Подхват горячего катода:** при подключении прибор не меняется, текущий ток
  удерживается без скачка.
- **▲ / ▼ по кривой** из любой точки; направление меняется на ходу.
- **Перехват:** СТОП (Esc), ручная уставка со скоростью, шаги ±1 А, передача
  на панель прибора и возврат.
- **Защиты:** обрыв, окно и скачки сопротивления, падение R при разогреве,
  P_max и dP/dt, ограничение тока источником, срабатывание защиты прибора, сбои связи.
  Больше 0,5 А одной командой программа ток не меняет никогда.
- **Журнал:** CSV каждые 0,5 с; по окончании сессии — Excel с датой, временем начала
  и окончания, итогами, событиями и графиками.

## Установка (Windows)

1. Python 3.8 или новее. Подойдёт Anaconda; иначе Python с python.org — при установке
   отметить «Add python.exe to PATH».
2. Скачать репозиторий (Code → Download ZIP или `git clone`) в папку, куда можно писать,
   например `C:\PR8_nakal\`.
3. Двойной щелчок по `Запуск.bat` — при первом запуске он сам поставит пакеты
   из `requirements.txt` и откроет окно.
   С Anaconda: в Anaconda Prompt `pip install -r requirements.txt`,
   затем `python pr8_cathode_app.py`.
4. Связь с прибором — по LAN (гальваническая развязка ноутбука от цепи накала):
   статический IP прибора, например `192.168.1.100`, ноутбука — `192.168.1.10`,
   маска `255.255.255.0`; порт Socket у ITECH обычно 30000.

Подробно, с проверками на каждом шаге — [docs/test_plan.md](docs/test_plan.md).

## Разработка

```
pip install -r requirements-dev.txt
pytest -q                     # ≈ 4 мин; тест окна требует дисплея
python tools/fake_itech.py --speed 60
```

Тесты гоняет GitHub Actions на Python 3.8 и 3.12 (Linux) и 3.12 (Windows).
Правила изменений и инварианты безопасности — в [CLAUDE.md](CLAUDE.md).

Настройки (`pr8_cathode_settings.json`) и журналы (`logs/`) создаются рядом с программой
и в репозиторий не попадают; журналы испытаний на приборе переносятся в `runs/` вручную.
