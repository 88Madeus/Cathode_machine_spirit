# Журналы испытаний на приборе

Сюда складываются журналы сессий с настоящим ITECH IT6012D-300-150 — этапы 1–5
[плана испытаний](../docs/test_plan.md). Сессии на модели и на эмуляторе сюда не кладём.

## Как добавить

1. В программе — «Папка журналов» (обычно `logs/` рядом с программой).
2. Скопировать файлы сессий этапа — `pr8_nakal_ГГГГММДД_ЧЧММСС.csv` и `.xlsx` с тем же
   именем — в подпапку `runs/ГГГГ-ММ-ДД_этапN/`, например `runs/2026-11-03_этап1/`.
   Файлы не переименовывать: по имени видно время начала сессии.
3. Рядом можно положить `заметки.md`: что делали, тексты неожиданных сообщений, значения
   для таблицы «Протокол испытаний».

CSV и Excel вне `runs/` и `docs/protocols/` git по-прежнему не берёт (`.gitignore`).
