# ПР-8 · Накал катода: установка, первый запуск и испытания

Программа вводится в работу за шесть этапов: от модели без прибора до полного цикла
0 → 88 А → 0 на катоде. К следующему этапу переходим, только когда выполнены все пункты
текущего; при любом непредвиденном сообщении — СТОП (Esc) и разбор.

## Порядок испытаний

Катод получает ток только с этапа 3 — после проверки связи и команд.

| Этап | Что проверяем | Переход к следующему, если |
| --- | --- | --- |
| 0 · Модель без прибора | Кнопки: СТОП, ▲/▼, панель, авария | Все знают, где СТОП и как вернуть управление |
| 1 · Связь, катод отключён | `*IDN?`, подключение, панель, обрыв LAN | Ошибок прибора нет; панель отдаётся и берётся |
| 2 · Выход на разомкнутые клеммы | CC и U_lim приняты, срабатывание OVP видно | Выход включается в CC; срабатывание OVP видно |
| **3 · Катод в вакууме, до 20 А** | Показания, перехват, обрыв связи на горячем | U(20 А) 0,66–1,16 В; ток − уставка ≤ 0,2 А |
| 4 · Полный цикл 0 → 88 → 0 А | ≈ 54 мин вверх, ≥ 30 мин удержание, ≈ 46 вниз | Цикл без тревог; U(88 А) 5,0–5,3 В |
| 5 · Удержание с разрядом | Зажигание и горение без ложных защит | Программа — в обычной работе |

## Установка

Нужен ноутбук с Windows и Python 3.8 или новее. Установка занимает 10–15 минут,
интернет нужен только для пакетов.

1. **Python.** Если на ноутбуке есть Anaconda (Spyder) — она подходит. Иначе — Python 3.12
   с python.org; в первом окне установщика отметить «Add python.exe to PATH». Проверка:
   `python --version` показывает 3.8 или выше.
2. **Программа.** Скачать репозиторий (Code → Download ZIP или `git clone`) в папку, куда
   можно писать, например `C:\PR8_nakal\`. Не в Program Files: рядом с программой
   создаются папка `logs` и файл настроек.
3. **Пакеты.** Двойной щелчок по `Запуск.bat`: при первом запуске он сам ставит pyvisa,
   pyvisa-py, matplotlib, openpyxl и открывает окно.
   - С Anaconda: Anaconda Prompt, `cd C:\PR8_nakal`, `pip install -r requirements.txt`,
     `python pr8_cathode_app.py`.
   - Без интернета в лаборатории: на другом компьютере
     `pip download -r requirements.txt -d wheels`, перенести папку `wheels`, на ноутбуке
     `pip install --no-index --find-links wheels -r requirements.txt`.
4. **Сеть с прибором (основной вариант).** LAN даёт гальваническую развязку ноутбука
   от цепи накала, которая плавает под потенциалом катода.
   - На приборе в меню LAN (System → LAN, путь сверить с руководством IT6000D) задать
     статический адрес, например `192.168.1.100`, маска `255.255.255.0`; записать номер
     порта Socket (у ITECH обычно 30000).
   - На ноутбуке: Параметры сети → Ethernet → IPv4 вручную: `192.168.1.10`,
     маска `255.255.255.0`, шлюз пустой.
   - Кабель напрямую или через коммутатор лаборатории. Проверка: `ping 192.168.1.100`.
   - Если Windows спросит про брандмауэр для Python — разрешить для частной сети.
5. **USB (запасной вариант).** Нужен драйвер VISA (NI-VISA или Keysight IO Libraries).
   USB связывает землю ноутбука с корпусом прибора, поэтому для работы с разрядом
   предпочтительнее LAN.
6. **Ноутбук.** Работать от сети. В Диспетчере устройств у Ethernet-адаптера на вкладке
   «Управление электропитанием» снять «Разрешить отключение этого устройства для экономии
   энергии». Сон и гашение экрана во время сессии программа запрещает сама.

Сброс настроек к протокольным: «Сбросить к протокольным» на вкладке «Кривая и пределы»
или удаление `pr8_cathode_settings.json` рядом с программой.

Без прибора связь по LAN можно проверить на эмуляторе: `python tools/fake_itech.py`,
в программе — LAN, `127.0.0.1`, порт 30000.

## Этап 0 — первый запуск на модели без прибора

Цель: каждый, кто будет работать с накалом, знает, где СТОП и как вернуть управление,
до того как подключён настоящий прибор. Около 20 минут.

Запустить `Запуск.bat`, выбрать «Модель без прибора», ускорение ×60, «Подключить».

- [ ] «▲ Вверх по кривой до 88 А» — ток растёт ступенями 3 → 1,8 → 2 А/мин, на 70 А выдержка.
- [ ] На ~30 А «▼ Вниз по кривой до 0» — разворот без скачка, затем снова ▲.
- [ ] Esc во время движения — «■ СТОП: ток зафиксирован».
- [ ] Ручная уставка 40 А, 5 А/мин → «Плавно»; затем −1 А и +1 А.
- [ ] «Передать на панель прибора» → «Вернуть управление программе».
- [ ] «Аварийно вниз до 0» — снижение 5 А/мин и выключение выхода.
- [ ] «Выключить выход сразу» — появляется предупреждение о термоударе; нажать «Нет».
- [ ] «Отключить» → «Папка журналов» → Excel-файл сессии: лист «Сессия» с датой, временем
      начала и окончания, версией программы, графики.

Переход к этапу 1: все пункты отмечены.

## Этап 1 — связь и команды, катод отключён

Проверяем, что прибор понимает программу, пока ошибка ничего не может нагреть: силовые
кабели накала сняты с выходных клемм прибора. Около 30 минут.

Сначала на передней панели прибора выставить аппаратные защиты — второй рубеж, чуть выше
пределов программы:

| Защита прибора | Выставить | Предел в программе |
| --- | --- | --- |
| OVP (напряжение) | 9 В | 8 В (VOLT:LIM) |
| OCP (ток) | 97 А | 95 А (максимум уставки) |
| OPP (мощность) | 650 Вт | 600 Вт |

Время нарастания и спада тока в приборе (I-Rise / I-Fall) оставить минимальным: плавность
задаёт программа, а заметное отставание тока от уставки она примет за ограничение
и заблокирует рост.

- [ ] «LAN (Ethernet)», IP и порт прибора → «Проверить связь» → «✓ Прибор ответил: ITECH…
      IT6012D-300-150…». Эта проверка ничего в приборе не меняет.
- [ ] «Подключить» → в журнале «Прибор: …» и «Выход выключен…»; на панели прибора —
      индикатор дистанционного режима.
- [ ] В журнале нет «Ошибки прибора: …» и нет «Прибор не отвечает на VOLT:LIM?». Если есть —
      переписать текст в протокол испытаний.
- [ ] «Передать на панель прибора» → кнопки панели снова работают. Записать, как на этом
      приборе вернуть местное управление самостоятельно (кнопка Local или сочетание):
      пригодится, если ноутбук зависнет.
- [ ] «Вернуть управление программе» → снова «Выход выключен…», без ошибок.
- [ ] Выдернуть LAN-кабель на 15 с → красная строка «✗ НЕТ СВЯЗИ»; вернуть →
      «Связь с источником восстановлена».
- [ ] «Отключить» → в журнале «Журнал сессии сохранён в Excel».

Остановиться и разобраться, если: «Не удалось подключиться» — смотреть подсказку (IP, порт,
кабель, занят другой программой); «Ошибки прибора» с кодом −113 — прибор не знает одну
из команд. Словарь команд (`SCPI`) стоит в начале `pr8_cathode_app.py` и сверяется
с IT6000D Programming Guide.

## Этап 2 — выход на разомкнутые клеммы

Проверяем, что прибор принимает режим CC, предел напряжения и включение выхода, а программа
видит срабатывание защиты прибора. Катод по-прежнему отключён; при включённом выходе
на клеммах до 8 В — не касаться. Около 20 минут.

- [ ] Ручная уставка 3 А, 1 А/мин → «Плавно» → подтвердить включение выхода. В журнале:
      «Режим CC, U_lim = 8.0 В, выход включён при 0 А»; на панели — приоритет тока и предел 8 В.
- [ ] Сразу за ним тревоги «Напряжение у предела U_lim = 8.00 В (ток 0.00 А…) — рост тока
      заблокирован» и «Рост тока остановлен». Уставка остаётся ≈ 0,01 А: на разомкнутой цепи
      программа ток не поднимает. Так же она поведёт себя, если цепь накала окажется не собрана.
- [ ] «▼ Вниз по кривой до 0» → «Ток 0 — выход выключен», на панели выход выключен.
- [ ] Срабатывание защиты прибора: «Передать на панель», выставить OVP 5 В, «Вернуть
      управление программе», снова ручная уставка 3 А. Ожидаемо: «Выход источника
      отключился сам: сработала защита прибора…», на панели — OVP, уставка тока в приборе 0 А.
- [ ] Сбросить защиту на панели и вернуть OVP 9 В.

Остановиться, если на первом шаге появилось «Прибор не перешёл в нужный режим…» (выход при
этом не включён: прибор не принял `FUNC CURR` или `VOLT:LIM`) или «Команда включения выхода
не подействовала» (блокировка или интерлок прибора). Текст сообщения — в протокол.

## Этап 3 — катод в вакууме, до 20 А

Проверяем показания и перехват управления на настоящем нагревателе, пока мощность
не больше 20–25 Вт. Около 1,5 часа.

Условия: камера откачана как перед обычным нагревом (в протоколах — 6–10·10⁻⁶ мбар),
охлаждение катодного узла включено, кабели накала подключены. На время этапа OCP прибора —
25 А: если случайно нажать ▲ до 88 А, прибор не даст току уйти выше.

- [ ] «Подключить» → «▲ Вверх по кривой до 20 А»: рост 3 А/мин, около 7 минут. Записать U при
      10, 15 и 20 А в протокол испытаний.
- [ ] В удержании на 20 А: разница «Ток» − «Уставка» не больше 0,2 А; R стоит; нет сообщений
      «Неправдоподобный отсчёт», «ток не следует за уставкой», «СКАЧОК R».
- [ ] Разворот: «▼ до 12 А», на ~15 А — «▲ до 20 А». Ток разворачивается без скачка.
- [ ] Esc во время движения → удержание; «−1 А» → плавно до 19 А, «+1 А» → обратно.
- [ ] Панель и возврат: «Передать на панель», на приборе медленно поставить 19 А, «Вернуть
      управление программе» → «Выход включён, уставка 19.00 А — удержание без изменений»,
      ток не дёрнулся.
- [ ] Обрыв связи на горячем: выдернуть LAN на 15 с — ток на панели не меняется; после
      возврата кабеля «Связь восстановлена», без тревог.
- [ ] Перезапуск на горячем: закрыть окно (подтвердить), запустить снова, «Подключить» →
      удержание текущего тока без изменений.
- [ ] Если при подключении было «Предел напряжения в приборе … — будет приведён к настройке»,
      то после первой команды движения — «Предел напряжения в приборе … → 8.00 В».
- [ ] «▼ до 0» → 3 А/мин до нуля, «Ток снижен до 0 — выход выключен». Вернуть OCP 97 А.
- [ ] В Excel-файле сессии график тока без ступенек, на листе «Журнал» уставка меняется
      не больше чем на 0,05 А за строку.

Переход к этапу 4: U при 20 А в пределах протокольных 0,66–1,16 В (R 33–58 мОм),
расхождение тока и уставки ≤ 0,2 А, ни одной неожиданной тревоги. Расхождение 0,3–0,5 А —
прислать журнал до этапа 4: при таком смещении программа может ложно блокировать рост.

## Этап 4 — полный цикл 0 → 88 А → 0

Первый рабочий нагрев по кривой из протоколов: разогрев ≈ 54 мин, удержание не меньше
30 мин, остывание ≈ 46 мин. Условия — как на этапе 3, OCP прибора снова 97 А, кривая
и пределы — протокольные.

- [ ] «▲ Вверх по кривой до 88 А»: 3 → 1,8 → 2 А/мин до 70 А, выдержка 3 мин, далее 1,1 и
      0,9 А/мин.
- [ ] На 60–80 А следить за давлением. Если оно растёт заметно быстрее, чем на прошлых
      нагревах (максимум в протоколах 1,3·10⁻⁵ мбар, 30.09), — Esc, дождаться откачки
      и снова «▲ до 88 А»: движение продолжится с текущего тока.
- [ ] Записать U при 40, 70 и 88 А. На 88 А по протоколам 05.10 и 06.10: U 5,09–5,22 В,
      P ≈ 450–460 Вт, R ≈ 58–59 мОм.
- [ ] Весь разогрев — без тревог и без вмешательства оператора.
- [ ] Удержание на 88 А не меньше 30 мин: U и R стоят; дрейф за это время записать.
- [ ] «▼ Вниз по кривой до 0»: 0,9 → 1,1 → 2 → 3 А/мин, в конце «выход выключен». Воздух
      в камеру не напускать, пока катод не остыл (не меньше 30 мин после выключения).
- [ ] В Excel-файле: дата, время начала и окончания, длительность, максимумы; график
      сопоставим с нагревом 06.10.

Успех: полный цикл прошёл без тревог, U на 88 А в пределах 5,0–5,3 В. После этого нагрев
можно вести программой в обычной работе, без разряда.

## Этап 5 — удержание с горящим разрядом

Проверяем, что зажигание и горение разряда не вызывают ложных срабатываний защит. На фоне
обычного измерительного дня: накал 88 А в удержании, He, поле катушек, Iр 13,9 А.

- [ ] Зажечь разряд как обычно. Возможно сообщение «СКАЧОК R … если только что зажгли
      разряд — это ожидаемо»: в удержании это только запись, ток не меняется. Записать R
      до и после зажигания.
- [ ] На фоне разряда показания U и I не скачут; нет «Неправдоподобный отсчёт» и
      «данные … с назад!». Это проверка развязки: цепь накала сидит под потенциалом
      катода (−100…−115 В).
- [ ] Если после зажигания накал снижают (катод догревается ионами) — «▼ до N А» или ручная
      уставка 1 А/мин; записать, до какого тока и как изменился разряд.
- [ ] Погасить разряд, затем «▼ до 0».

Если защита сработала ложно (например, запустилось «АВАРИЙНОЕ СНИЖЕНИЕ» из-за окна R),
Esc останавливает и его. После этого — прислать журнал сессии, пороги поправим
по реальным данным.

## Если что-то пошло не так

Главное: источник сам держит последнюю уставку, поэтому сбой программы или связи сам
по себе не меняет ток катода. Торопиться с выключением выхода не нужно.

| Ситуация | Что делать |
| --- | --- |
| Надо немедленно остановить изменение тока | Esc или «■ СТОП»: ток фиксируется. Работает и во время аварийного снижения |
| Надо быстро, но плавно снять накал | «Аварийно вниз до 0»: 5 А/мин, с 88 А ≈ 18 мин, в конце выход выключается |
| Красная строка «НЕТ СВЯЗИ» | Ничего не нажимать, проверить кабель и сеть. Не вернулась за минуту — управлять с панели прибора |
| Программа зависла или ноутбук выключился | Вернуть местное управление на приборе (способ записан на этапе 1) и снижать ток ручкой не быстрее 3 А/мин |
| «ТОК ОГРАНИЧЕН ИСТОЧНИКОМ» | Рост заблокирован, уставка подтянута к току. По панели понять, какой предел сработал; снижать ток можно как обычно |
| «R ПАДАЕТ ПРИ РОСТЕ ТОКА» или «СКАЧОК R» | Ток уже зафиксирован. Проверить контакт трубок охлаждения с корпусом (как 05.10) и давление, затем ▲ или ▼ |
| «ТРЕВОГА: R вне окна» → аварийное снижение | Проверить цепь накала и давление; если срабатывание ложное — Esc |
| «ОБРЫВ ЦЕПИ НАКАЛА» | Выход уже выключен. Проверить нагреватель и контакты на вводе |
| «Выход источника отключился сам» | Сработала защита прибора: на панели видно какая (OVP, OCP, OTP). Уставка в приборе уже обнулена |
| Опасность для людей или установки | Аварийное отключение по регламенту лаборатории, не через программу. «Выключить выход сразу» снимает ток мгновенно — для LaB₆ это термоудар |
